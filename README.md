**先独立写作，再把每次反馈用到修改里。**

爱雅思写作把 **写作、批阅、修改** 连成一个完整的练习过程：先在接近机考的界面里完成自己的作文，再查看与原句关联的批注，最后一边修改、一边向 AI 追问。初稿、修改版本、批阅与聊天记录保存在本地，方便以后回看。

> **v2 已发布：** 提供 Apple Silicon（M 系列）Mac 安装包，以及学术类 128 题、培训类 28 题和 Prompt 下载。安装包未经 Apple 公证，首次打开请阅读[安装说明](docs/INSTALL.md)。AI 功能需要自行配置接口与 API Key，调用费用按服务商规则计算。

## 快速了解与开始

### 一次练习怎样运转

**自己写 → 点击批阅 → 对照原句看建议 → 修改并追问 → 保存版本、回看问题。**

- **本地练习**：不配置 AI，也可以选题、写作、计时和自动保存。
- **AI 辅助**：自行配置大模型后，可获得原文关联批注、局部修改建议和解释，继续聊天讨论，也能归纳多篇作文的共性问题。

批阅时，程序先保存并固定这次送审稿，批注始终对应这一版。修改另存；在“批阅”和“修改”之间切换会查看已有内容，需要新反馈时再点击“重新批阅当前稿”。

### 第一次使用，按这五步

1. **下载安装**：[下载 v2](https://github.com/tomot-ch/aielts-writing/releases/tag/v2)，将应用拖入“应用程序”后打开。当前提供 M 系列 Mac 安装包；首次打开遇到系统拦截时，参照[安装说明](docs/INSTALL.md)。
2. **准备一篇练习**：选择长期保存的数据目录，点击“直接开始写作”；也可先[下载题包](docs/downloads/README.md)，解压后在“准备&其他 → 下载或自行上传题目”批量导入 `images/` 中的 PNG，再选题写作。
3. **启用 AI（可选）**：进入“准备&其他 → 语言大模型配置”。在“模型连接”填写接口、Key 与模型并完成测试；在“提示词管理”选择内置提示词或添加自己的要求；最后在“配置管理”把模型与提示词搭配、保存并启用。
4. **写完再批阅**：完成正文后点击“批阅”，等待结果；在批阅页点击原文标记或右侧卡片，对照原句、局部改句和解释。
5. **动手修改与追问**：批阅成功后点击“修改”，一边改文章，一边向 AI 追问。修改自动保存，点击“保存修改版本”可留下一版；需要再次评阅时点击“重新批阅当前稿”。

### LLM 与 Prompt 怎样配合

**LLM 是你选择的大模型，Prompt 是随请求发送的指导要求，应用负责组织材料、显示批注和保存记录。** 配置模型后，可以先使用内置 Prompt，自定义内容可以后续再加。

| 部分 | 在练习中负责什么 |
| --- | --- |
| LLM / 模型连接 | 通过你配置的接口理解题目和文章，生成批阅、建议与后续回答；带图题目需要可用的图片能力。你需自行配置 API Key，调用费用按服务商规则计算。 |
| 内置前置规则 | 程序自动加入四项评价、证据与不确定性要求，按任务附上 Academic Task 1 专项，并规定批注的结构，方便关联原句。 |
| 自定义 Prompt | 补充反馈重点、语言与修改方式，例如“优先指出论证跳跃，先解释原因，再给局部改法”。无需重复粘贴整套前置规则。 |
| 启用的配置 | 将模型与 Prompt 搭配；后续请求使用当前启用配置。可按用途手动切换，目前没有评阅／修改两套 Prompt 自动切换的开关。 |

首轮批阅的过程是：**题目与固定稿 + 内置规则 + 选定的补充 Prompt → 模型返回反馈 → 程序校验并呈现原句关联批注**。默认以分析和局部建议为主，全文改写需明确提出要求；反馈与教学预估供练习参考。

稿件、版本、批阅和聊天保存在本地；使用 AI 时，相关材料和对话上下文会发送到你配置的服务。API Key 使用 macOS 钥匙串保存。更多上下文设置见[使用指南](docs/USAGE.md#7-调用方式与上下文管理)。

### 可以用它完成什么

题目图片练习与可选计时、原句关联批阅、四色笔迹修改、AI 追问、保存版本、多篇问题复盘，以及稿件 Word 和批阅／聊天 Markdown 或 Word 导出。下方按真实操作顺序展示主要界面。

## 界面与功能

*以下截图使用当前应用组件与样式，题目和作文为自拟材料，批注与聊天为合成示例，用于展示操作，未调用真实模型或展示真实评分。*

### 写作：先完成自己的表达

题目与正文并排展示，支持调整栏宽、隐藏题目和专注全屏。字数实时更新，计时默认关闭；Task 1、Task 2 可分别开启 20、40 分钟计时，超时后仍可继续写。

写作区关闭可控的拼写检查、自动更正、续写和系统行内预测，保留正常输入法候选。内容自动保存，没有题目也能直接开始。

![新版写作页：题目与正文并排，下方为批阅和修改入口](docs/images/01-writing.jpg)

### 批阅：让反馈回到原文

写完后点击 **“批阅”**，应用先保存并固定这次送审稿，再发起评阅。完成后自动进入批阅页：左侧为只读的送审原文，右侧为批注卡片。

- 点击原文标记或批注卡片，双向定位对应内容。
- 对照原句、局部改句和中文解释，区分确定错误、可优化建议与待核实信息。
- 删除线与新增标记帮助看清建议中的变化；无法可靠定位的内容会说明情况。
- 批注始终对应当时的固定稿，不会随着后续编辑漂移到新文字上。

![新版批阅页：选中批注卡片后，左侧原句高亮，右侧显示修改前后与解释](docs/images/02-annotated-review.jpg)

### 修改：动手改，也能继续问

批阅成功后点击 **“修改”**，进入左侧文章、右侧 AI 聊天的独立页面。你可以询问一条建议为什么成立，讨论论证怎样展开，再自己修改正文。

修改稿自动保存；点击 **“保存修改版本”** 可固定这一版。黑、蓝、绿、红四种笔迹颜色只影响后续输入，适合记录自己的修改重点。笔迹颜色由你选择，与批注中的删改对照分别呈现。

**“批阅”和“修改”可以来回切换。** 查看已有批阅不会重复请求模型，也不会自动提交正在编辑的修改稿；需要新反馈时，明确点击 **“重新批阅当前稿”**。

![新版修改页：左侧用蓝绿笔迹修改文章，右侧继续围绕批阅结果提问](docs/images/03-revision-chat.jpg)

## 把一次反馈，积累成长期练习

- **多篇复盘**：自行选择每篇作文的固定版本，归纳共性问题，报告保留来源记录。
- **问题记录**：单篇问题可以编辑或移除，整理出下一次值得自查的地方。
- **自选模型与 Prompt**：“模型连接”“提示词管理”“配置管理”分开设置，最多保存五组常用配置；欢迎按自己的练习需要调整评阅和修改辅助要求。
- **可选上下文管理**：支持普通兼容接口与 Responses；仅在接续能力验证通过后使用服务端历史，仍保留本地问答。
- **本地归档与导出**：稿件导出为保留笔迹颜色的 Word；分析、聊天支持 Markdown 或 Word。数据目录可迁移，删除内容先进入本地回收站。

应用内置通用批阅规则，并为 Academic Task 1 加入图表、概述、分组与数据精度方面的要求；自定义 Prompt 在此基础上补充关注点。默认聚焦分析和局部建议，只有明确提出要求时才提供全文改写。

## 常见问题

**数据保存在哪里？使用 AI 时会外发吗？**

写作、版本、批阅与聊天保存在你选定的本地目录。AI 请求会将相关作文、题目材料、提示词和对话上下文发给你配置的服务；服务端接续还受该服务的存储规则约束。API Key 使用 macOS 钥匙串保存。

**不开 AI 能使用吗？**

可以独立写作、自动保存并使用本地题库。当前界面的“修改”页在成功完成批阅后解锁；它是写后修改与聊天流程的一部分。

**能在网页或 Windows 上使用吗？**

浏览器入口仅为交互原型，数据放在当前浏览器的 `localStorage`，不提供完整桌面功能。Windows 尚未提供经过验证的发行版。

**AI 批阅能给出官方分数吗？**

批注、建议和教学预估仅供练习参考，受模型与题目识别质量影响；本项目与 IELTS 官方无隶属关系，不承诺考试成绩。

**能直接导入 PDF 或下载在线题库吗？**

可以从 [Release 下载题包](https://github.com/tomot-ch/aielts-writing/releases/tag/v2)，解压后导入 PNG；也支持 JPEG、WebP。应用内自动下载尚未接入，ZIP 和 PDF 不能直接从图片导入入口导入。
